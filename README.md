# Razcel Fernandes Portfolio

Portfolio website built with Next.js, Tailwind CSS, and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Replace placeholders

- Profile photo: `public/profile/profile.jpg`
- CV: `public/cv/razcel-fernandes-cv.pdf`
- Project images: `public/projects/*`
- GitHub / LinkedIn / WhatsApp / email links in `components/Portfolio.tsx`
- Certification files/images in `public/certificates/`

## Deploy to Vercel

1. Create a GitHub repository.
2. Upload all files in this project.
3. Go to Vercel and choose **Add New Project**.
4. Import the GitHub repository.
5. Keep the default Next.js settings.
6. Click **Deploy**.

Every future push to GitHub will trigger a new deployment.
